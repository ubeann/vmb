# List kit parity sheet

The list kit was built from the prototype `C3kd2` (ADR-0051 to ADR-0053). The prototype is evidence; this sheet and the ADRs are the spec (`docs/agents/ui-prototype-round.md`). One row per component of the final variant: the exact value, where the prototype has it, the round that chose it, the ADR rule it implements, and what `master` does. A ticket quotes a row, never "match C3kd2".

**Read the prototype** at the pinned commit; its line numbers below are for that file as it stands there:

```sh
git show 56f4273:apps/web/src/routes/prototype/list-kit/VariantB.svelte   # the lines below
git show 56f4273:apps/web/src/routes/prototype/list-kit/SearchBox.svelte  # the search rows
git show 56f4273:apps/web/src/routes/prototype/list-kit/+page.svelte      # which flags C3kd2 turns on
```

`C3kd2` is the last of the `K_SERIES` and turns every flag on, with `middle="desc"`, `inactive="dim"`, `sortStyle="sections"`, `toolTone="c"`, `radius="scaled"` and `dates="beside"`; the `FOLD` and `TOOL` blocks (VariantB 329–348) are the container-query classes. The branch is `t3/improve-table-filter-header-ui`; it never merges, so if it is ever deleted the SHA above still resolves from a clone that fetched it.

**Round** is the prototype's own numbering, from the comments on its props (VariantB 130–244) and the commit that records each owner pick; `Qn` is the 2026-10-09 grilling's question (ADR-0051, Context). **Master** says `match`, `fixed in #409` (the audit's finding, now closed), or `deviation Dn` (decided later, with its reason in [Deviations](#deviations)).
